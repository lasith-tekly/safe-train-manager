## Color Key for ASCII Mockups

```
▓ = Filled/Used (Green, Yellow, or Red depending on percentage)
░ = Empty/Available (Light gray)
● = Active/In Progress (Primary blue)
○ = Inactive/Not Started (Gray)
★ = Rating/Priority indicator (Yellow)
```

   - Active: Green dot

   - In Progress: Blue dot
   - Warning: Yellow exclamation triangle

   - Section padding: 24px
